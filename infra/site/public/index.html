first time opening it

the app is free and not yet signed with a paid developer certificate, so your computer asks once if you trust it. this is expected. after the first time it opens normally.

macOS: "Apple could not verify Manga Cleaner"
  1. open the .dmg and drag Manga Cleaner into Applications.
  2. open Manga Cleaner from Applications. macOS blocks it. click Done (or Cancel).
  3. open System Settings › Privacy & Security. scroll down to Security.
  4. next to "Manga Cleaner was blocked", click Open Anyway. enter your password.
  5. open Manga Cleaner again and click Open Anyway.

if macOS says the app "is damaged", run this in Terminal, then open it again:
xattr -dr com.apple.quarantine "/Applications/Manga Cleaner.app"

if you saved a cloud GPU profile, an update can ask for your login keychain password. click Always Allow.

Windows: "Windows protected your PC"
  1. run the downloaded -setup.exe.
  2. if a blue SmartScreen box opens, click More info, then Run anyway.
  3. if your browser marks the download as unsafe, open its downloads list and pick Keep.

it installs for your user only, so it needs no admin rights. you do not need to install anything else: the installer fetches WebView2 if Windows lacks it, and the Visual C++ files ship with the app.

Linux: install the .deb or run the AppImage

on Ubuntu or Debian, install the .deb. apt gets every library it needs:
sudo apt install ./MangaCleaner_*_linux-x86_64.deb

on other distros, make the AppImage executable and run it:
chmod +x MangaCleaner_*_linux-x86_64.AppImage

if the AppImage does not open and mentions FUSE, install libfuse2 (on Ubuntu 24.04 and later: sudo apt install libfuse2t64), or start it with --appimage-extract-and-run.

first launch: model downloads

the installer is small. the first launch walks you through the model downloads: about 350 MB on macOS, about 520 MB on Windows. keep the app open until they finish. anything you skip can be fetched later from Settings › Models.

demo: understand how lama works. a chapter detect run, then text over diagonal hatching cleaned with manga-LaMa from the right-click menu ("clean with"). LaMa rebuilds the hatching lines behind the text instead of painting flat paper.

use the lightest engine that does the job: fill for flat paper, manga-LaMa (the default) for screentone, halftone and line art, FLUX.2 Klein for the rare region nothing else can reconstruct, and cloud on your own GPU account, per region, when you choose it.

  • automatic cleaning pipeline: detect speech bubbles and free text, gate to Japanese script, fit masks, route to an engine, and composite
  • every cleaned region is a non-destructive layer: re-run with a different engine, tune, or delete
  • six manual tools: auto clean, brush, shapes, AI mask brush, content-aware fill, and clone / heal
  • long-strip webtoons with virtual stitching, content-minimum splitting, and bounded-memory streaming
  • pixel-exact export: untouched pixels stay bit-identical, ICC profiles and metadata preserved
  • export to PNG, TIFF, layered PSD, mask files beside each page, or CBZ
  • completely local and offline: no account, no uploads, model weights verified by SHA-256
  • cryptographically signed auto updates

this is a beta: complex backgrounds can leave faint marks, keep your originals
